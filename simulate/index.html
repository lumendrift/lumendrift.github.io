Simulation

See exactly how an AI agent shops your store

Reference agents execute the full intent — discover, authenticate, search, cart, checkout, confirm — and surface every break.

How agents behave

Reference agent semantics

Intent-driven

Agents accept a natural-language intent ("buy a 4k monitor under $400 with overnight shipping") and translate it into protocol calls.

Spec-strict

Every response is parsed against the UCP schema. Drift triggers immediate failure rather than silent compensation.

Deterministic

Simulation results are deterministic per domain. Re-run for the same baseline; diff for regression analysis.

Why simulate

Validation tells you what; simulation tells you why

A green manifest validation can still mean broken agent flows in production. Simulation closes the gap.
