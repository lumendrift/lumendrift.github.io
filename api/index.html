Quickstart

Validate a domain in 10 lines

curl

Any backend that can hit an HTTPS endpoint can run validation.

bash
curl -X POST https://api.ucp.dev/v1/validate \
  -H "Authorization: Bearer $UCP_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"domain": "shop.example.com"}'

TypeScript SDK

Strict types, tree-shakeable, zero runtime deps.

ucp.ts
import { UCP } from "@ucp/sdk";
 
const ucp = new UCP({ apiKey: process.env.UCP_API_KEY! });
 
const report = await ucp.validate({ domain: "shop.example.com" });
 
if (report.grade < "B") {
  throw new Error(`Regression: ${report.grade} (${report.score})`);
}
