Schema

What the manifest declares

Required fields

Every UCP manifest must include a version, a store block, at least one capability, an identity scheme, and a contact endpoint for agent operators.

  • version — UCP protocol version
  • store — name, domain, platform
  • capabilities — endpoint + methods per capability
  • identity — accepted agent identity schemes
  • payments — supported payment instruments
  • contact.agent_relations — operator email

Implementation

Publish the manifest at the standard well-known location.

implementation
# 1. Save manifest
mv ~/Downloads/ucp.json ./public/.well-known/ucp.json
 
# 2. Verify it's reachable
curl -sS https://shop.example.com/.well-known/ucp.json | jq
 
# 3. Validate
ucp validate shop.example.com
