Security

How UCP secures customer data, validation traffic, and credentials.

Transit

TLS 1.2+ everywhere. HSTS and modern cipher suites enforced.

At rest

AES-256 at rest with keys rotated quarterly.

Read-only by default

Validation crawls public endpoints only. Simulation runs against test carts where supported. Customer keys are scoped to the minimum required for validation.

Responsible disclosure

Report security issues to security@ucp.example.com. We acknowledge within 24 hours.
