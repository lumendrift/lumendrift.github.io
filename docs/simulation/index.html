Simulation

How reference agents execute the full shopping intent against a live storefront.

Reference agents

UCP ships reference agents under the reference-agent/ namespace. Each agent represents a behavior class (cautious, aggressive, multi-step) to surface different failure modes.

Intents

An intent is a natural-language goal. The agent decomposes it into protocol calls. Default intent: "purchase one product matching natural-language query".

Trace anatomy

Each trace is an ordered list of steps. Each step has a status, duration, and log lines.

text
step discover
discover manifest: ok (180ms)
 
step auth
authenticate agent: ok (230ms)
 
step search
search catalog: degraded response, schema drift detected
 
step checkout
checkout: blocked — endpoint returned 4xx or missing field
