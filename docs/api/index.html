API reference

Authentication, endpoints, errors, and webhook payloads.

Authentication

Bearer tokens, scoped per workspace and environment.

bash
Authorization: Bearer ucp_live_xxxxxxxxxxxxxxxx

Endpoints

  • POST /v1/validate — run validation against a domain
  • GET /v1/reports/{id} — fetch a stored report
  • POST /v1/simulate — execute a simulation
  • GET /v1/domains — list monitored domains
  • POST /v1/manifests/generate — generate a manifest

Errors

All errors follow a consistent envelope:

json
{
  "error": {
    "code": "domain_unreachable",
    "message": "Could not resolve shop.example.com",
    "request_id": "req_abc123"
  }
}

Webhooks

Signed with HMAC-SHA256 in the X-UCP-Signature header.
