Scoring

How AI commerce readiness is measured

A single 0–100 score and an A–F grade, weighted across six capability categories.

Methodology

Weighted category model

Six categories. Six weights. One score.

Each category emits a 0–100 sub-score from deterministic checks. The platform score is the weighted sum, rounded to the nearest integer.

CategoryWeightWhat we measure
Manifest schema25%Discoverability, version, required fields, signatures.
Endpoint reachability20%HTTP correctness, content types, error envelopes.
Authentication & identity15%Declared agent identity schemes, key rotation.
Catalog accessibility15%Required fields, currency, pagination, locale.
Checkout flow15%Idempotency, totals, taxes, error semantics.
Protocol compliance10%CORS, rate limits, retry semantics.

Grades

Grade thresholds

A

90–100

Production-grade. Agents transact reliably with minimal compensation.

B

80–89

Healthy. A few categories below spec; agents complete most intents.

C

65–79

Conditional. Agents complete simple intents; complex flows degrade.

D

50–64

At risk. Agents fail more often than they succeed.

F

0–49

Unready. Agents bounce. Implement before opening to agent traffic.
